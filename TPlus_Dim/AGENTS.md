# T+ Dim

- Giao diện và tài liệu bằng tiếng Việt, theo font/màu của T+ Cabinet.
- Chỉ triển khai `tplus_dim.rb` và các file liệt kê trong `dev/deploy.ps1` vào SketchUp 2022.
- Không thay đổi T+ Cabinet hoặc các plugin khác.
- Kiểm tra Ruby, luồng vùng chọn và UI trước khi đóng gói.
- Phân biệt kiểm thử mô phỏng với kiểm thử thực tế trong SketchUp.
